# Aufgabe: Klasse Person

Erstelle eine Klasse `Person`, die eine Person mit Namen und Alter beschreibt.

## Anforderungen

1. Die Klasse hat zwei private Attribute: den Namen (Text) und das Alter (ganze Zahl).
2. Ein Konstruktor nimmt Name und Alter entgegen und initialisiert die Attribute.
3. Die Methode `getName()` gibt den Namen zurueck.
4. Die Methode `getAlter()` gibt das Alter zurueck.
5. Die Methode `hatGeburtstag()` erhoeht das Alter um eins.
6. Die Methode `beschreibung()` gibt einen Text zurueck, der Name und Alter enthaelt.
