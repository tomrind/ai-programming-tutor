# Aufgabe: Klasse Ticketautomat

Erstelle eine Klasse `Ticketautomat`, die Fahrkarten zu einem festen Preis verkauft.

## Anforderungen

1. Private Attribute fuer den Ticketpreis, das eingeworfene Geld und die Gesamteinnahmen.
2. Ein Konstruktor nimmt den Ticketpreis entgegen.
3. `geldEinwerfen(int betrag)` erhoeht das eingeworfene Geld.
4. `ticketDrucken()` bucht den Preis auf die Einnahmen und setzt das eingeworfene Geld zurueck.
5. `zaehleBis(int grenze)` gibt zur Uebung alle Zahlen von 1 bis zur Grenze aus.
